# Resumos e Exercícios - Sistemas Operativos (SO)

Repositório de apoio ao **Mini-teste de Sistemas Operativos**, com resoluções das aulas, exercícios de treino em Bash e C, fichas, um teste modelo e sumários teóricos.

> **Nota:** nem todos os exercícios estão resolvidos ou 100% completos. Isto aplica-se a todo o repositório, não apenas às aulas.

---

## Estrutura do Repositório

### Aulas
Aulas de SO sobre Bash e C. Nem todos os exercícios estão completos.

### Codigos base SO
Códigos e PDFs fornecidos pelo professor como material de apoio. Como correspondem às aulas não resolvidas, também podem ser usados como base para resolver os exercícios das aulas.

### Exs_Sem_Enunciado
Exercícios feitos por mim, sem enunciado.

### Ficha_C_dados
Ficha de C sem concorrência, com exercícios para treinar.

### Ficha_Concorrencia
Ficha de C com concorrência, com exercícios para treinar.

### PDF_Sumários
PDFs com os sumários da matéria, úteis para revisão antes da avaliação.

### Teste_Modelo_SO_pacote.
Teste modelo para treinar.

---

## Como compilar os ficheiros em C

Para testar qualquer exercício em C no terminal Linux:

```bash
gcc -Wall -Wextra nome_do_ficheiro.c -o programa
./programa
```
